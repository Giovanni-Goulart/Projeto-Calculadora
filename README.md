# Projeto-Calculadora
🍖 Calculadora de Churrasco

Uma aplicação web moderna e responsiva desenvolvida para calcular automaticamente a quantidade ideal de carnes, bebidas e acompanhamentos para um churrasco.
O projeto foi desenvolvido utilizando HTML5, CSS3 e JavaScript, com foco em:
UI moderna
Responsividade
Boa experiência do usuário (UX)
Código limpo e organizado
Design profissional

🚀 Demonstração

O sistema permite informar a quantidade de:

👨 Homens
👩 Mulheres
👶 Crianças

E calcula automaticamente:

🥩 Carne bovina
🍗 Frango
🌭 Linguiça
🥤 Refrigerante
🍺 Cerveja
